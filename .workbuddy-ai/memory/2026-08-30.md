### LESSONS LEARNED (reusable — apply to any agent route work)
1. **Do NOT mask config/env in the `details` response.** That text round-trips
   through the UI editor; masked placeholders (`••••`) get persisted back on the
   next save and CORRUPT the config file. A hermes masking fix was applied then
   reverted for exactly this reason. Safe masking needs a UI contract change
   first (separate read-only masked field, or a sentinel save-config rejects).
2. **Inside shell-script template literals use `#` for comments, not `//`** —
   `//` is executed by the shell as a command path.
3. **Never put backticks inside a JS template literal that becomes a shell
   script**, even inside a `#` shell comment — it terminates the literal.
4. `${UNIT}` = `openclaw-gatew""ay` relies on the shell collapsing `""`.
   Must be double-quoted or unquoted; single quotes preserve `""` literally and
   match nothing.

## Sandbox blocker — root cause narrowed (2026-08-30, ~17:00)
- Error: `SandboxError(0xFFFFFFFF): Failed to spawn sandbox-exec:
  No such file or directory (os error 2)` on macOS **27.0 (26A5416b)**.
- `/usr/bin/sandbox-exec` **DOES exist** (Read resolves it as a binary file).
  So ENOENT is not "binary deleted" — it is exec failing on an existing file:
  missing/invalid dylib dependency (`libsandbox`) or a stub that no longer
  resolves. macOS 27 SDK deprecates `sandbox.h` / `sandbox_init`; Apple has
  been stripping `libsandbox` from the base system while leaving the stub.
- Same failure hit OpenAI Codex CLI on new macOS; their accepted fix was
  **environment detection + graceful degrade to no-sandbox**, not a hard crash.
- Confirmed: Bash(127, even with sandbox off), Grep, subagents all dead.
  Read / Glob / Write / Edit still work. Glob is workspace-scoped — absolute
  paths outside `/Users/katanyoo/Desktop/monitor` silently return nothing.
- Remediation ladder (user must run in their own Terminal.app):
  1. `ls -la /usr/bin/sandbox-exec; file /usr/bin/sandbox-exec;
     otool -L /usr/bin/sandbox-exec; ls /usr/lib/libsandbox*` → stub vs dylib
  2. `xcode-select --install` → reinstall Command Line Tools
  3. `softwareupdate --install --all`, then Recovery → Reinstall macOS
  4. Update WorkBuddy AI to a build that degrades gracefully instead of
     requiring Seatbelt (report the bug upstream)
- Interim: user runs `bash scratch/verify-agent-routes.sh` themselves and
  pastes output back; I can still edit files, just not execute them.
