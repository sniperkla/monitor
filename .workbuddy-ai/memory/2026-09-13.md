### Reported but NOT changed (structural, out of chosen scope)

- **`src/components/AgentWebUIView.js` (730 lines) is unreachable.**
  `openEmbeddedWebUI` branches on `if (openWindow)`; `openWindow` is a plain

### Gotcha that cost real time — `relayInfo` has no `webProxyPort`

`src/utils/relayStatus.js` *derives* `webProxyPort` from `relays[]`, but
AppContext's `SET_RELAY_INFO` payload is `{ connected, relays, checkDone }`
(`AppContext.js:606`). So `relayInfo.webProxyPort` is `undefined` at every
consumer and the port silently never rendered. Derive it from
`relayInfo.relays.find(r => r.webProxyPort > 0)` — same expression relayStatus
uses. **The card rendered perfectly and the feature still didn't work**; only a
real render caught it.

### Finding — the card's relay-off branch is dead

With no relay, the **app-level** gate replaces the entire AI Agents view
("Local Relay Required / Start Local Relay"), so the card never mounts. Verified
both cold-start AND mid-run (relay flipped off after the card was up, nothing
dispatched, app poller left to notice) — the app gate won both times. The
branch was equally dead before this change; its copy was just corrected.
