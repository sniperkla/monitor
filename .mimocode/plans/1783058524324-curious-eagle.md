# R2 Backup Storage — Auto-upload to Cloudflare R2

## Problem
Backup downloads currently stream through the Next.js server (remote SFTP → server → browser). The user wants backups stored in Cloudflare R2 for direct download.

## Solution
After a backup completes on the remote server, automatically stream it to R2. Return a presigned download URL so the user downloads directly from R2 — no server proxy needed.

## Environment Variables Required
```
R2_ACCOUNT_ID=<cloudflare-account-id>
R2_ACCESS_KEY_ID=<r2-api-token-access-key>
R2_SECRET_ACCESS_KEY=<r2-api-token-secret-key>
R2_BUCKET_NAME=<r2-bucket-name>
R2_PUBLIC_DOMAIN=<optional-custom-domain>  # e.g. backups.example.com
```

## Changes

### 1. Install dependencies
```bash
npm install @aws-sdk/client-s3 @aws-sdk/s3-request-presigner
```

### 2. New file: `src/lib/r2.js` — R2 client utility
- Create S3Client pointing to R2 endpoint (`https://{accountId}.r2.cloudflarestorage.com`)
- Export `uploadStreamToR2(key, readableStream, contentType)` — streams upload via `Upload` from `@aws-sdk/lib-storage`
- Export `getPresignedUrl(key, expiresIn = 3600)` — generates presigned GET URL

### 3. New endpoint: `src/app/api/server-backup/upload-r2/route.js`
- POST handler, requires auth session
- Accepts `connectionId`, `filePath`, `filename` in request body
- Uses `getSshConfig(connectionId)` + `sftpReadStream()` from `_ssh.js` to get a readable stream from the remote server
- Calls `uploadStreamToR2()` to stream directly to R2 (key: `backups/{connectionId}/{filename}`)
- Returns `{ success: true, downloadUrl: <presigned-url>, key }`

### 4. Update: `src/apps/ServerBackupApp.js`
- Add `r2UploadUrl` state
- In `pollStatus` completion handler (line 88-93): after backup completes, auto-call `/api/server-backup/upload-r2` in the background. Show "Uploading to cloud..." indicator. On success, set `r2UploadUrl`.
- Update download button: if `r2UploadUrl` exists, open it directly (it's a presigned URL — no auth headers needed, `window.open` works). Otherwise fall back to the existing `apiFetch` blob download.
- Add uploading state indicator next to the download button.

### 5. Revert previous fix (no longer needed)
The `handleDownload` blob-download fix from the previous task is no longer needed since R2 presigned URLs work with `window.open()` directly. Revert to simpler code.
